# Architecture

The MV3 extension owns the YouTube Music track source and WebSocket to Atlas. It reads the visible player bar clock and actual media clock, uses the media clock during a seek or incomplete autoplay transition, and also confirms autoplay from a reset and advancing player-bar clock if the media clock stays continuous. Even if the two clocks have different absolute origins, short media progress between player-bar ticks supplies sub-second lyric timing; after an autoplay confirmation, a stalled player bar also advances by elapsed media progress. A stable track is reported with its album, artwork, and position. LRCLIB lookup prefers close duration, full artist and the album where available; it rejects line timelines that outlast the recording. The display keeps the existing lyric, artwork-only and standby states, interpolates playback locally, and schedules each line from its LRC timestamp. The extension sends an authoritative playback correction once per second; the display renders the current line immediately without a fade. LRCLIB timestamps may themselves be wrong for a given recording; neither metadata nor playback position can prove the vocal is aligned to a specific lyric line.

The separate Windows PowerShell companion uses Core Audio to read the default multimedia output's master volume and mute state and to apply explicit remote changes. Its `HELLO` role is `volume`, and only it may send `MASTER_VOLUME_STATE`. Atlas tracks this independently from the music source. `SOURCE_STATE` can never change the displayed master level or trigger a command. `SET_VOLUME` goes only to a connected Windows volume companion after Atlas checks the 75% tablet cap; the companion checks the cap again. `CONTROL_COMMAND` still goes only to the YouTube Music extension. Desktop reports above 75% are preserved and shown, while the tablet thumb cannot command above 75%. On companion disconnect, the slider disables with volume unknown rather than inheriting the HTML media volume. The companion polls changes and reconnects automatically. The old browser media volume guard still prevents unintended site volume resets, but no Galaxy command is sent to the browser media element. This LAN protocol has no user authentication; do not expose Atlas to the Internet.

Protocol v3 is in `shared/protocol.ts`. A source HELLO optionally carries the extension build for Atlas diagnostics; `1.0.10` is this release. Only validated messages cross role boundaries. A source disconnect invalidates interpolation, and a new source starts with a blank snapshot. The simulator uses a loopback source connection, never production display UI. An updated extension build and YouTube Music tab reload are required when upgrading from v2.
